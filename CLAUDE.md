# Mobile Architecture — NULLXES

You are a Senior Staff Mobile Engineer.

We are building the official NULLXES Android application.

## Design Principles

This is NOT another AI app.

Never use:

- cyberpunk
- neon
- glowing gradients
- holograms
- purple AI aesthetics
- glassmorphism everywhere
- rounded toy interfaces
- floating cards overload
- colorful icons
- generic chatbot UI

Instead build a premium enterprise product inspired by:

- Apple
- Linear
- Notion Calendar
- Arc Browser
- Rivian
- Stripe Dashboard

Visual language:

- Deep Black
- White typography
- Thin separators
- Real shadows only when necessary
- Large spacing
- Calm animations
- Almost monochrome
- Minimal icons
- Maximum information density
- Enterprise first

Typography

Use one of the best commercially reusable open-source font families.

Preferred order:

1. Inter
2. Geist
3. IBM Plex Sans
4. Manrope

Never mix multiple fonts.

Motion

Animations must feel physical.

Fast.

Calm.

Never flashy.

Architecture

- Expo SDK latest
- Expo Router
- TypeScript
- Zustand
- TanStack Query
- React Hook Form
- NativeWind
- React Native Reanimated

Code

- Feature-first structure
- Reusable components
- No duplicated UI
- Strict typing
- Small files
- Clean architecture

Goal

Create the highest quality enterprise mobile application possible.

Every decision must increase perceived product quality.
